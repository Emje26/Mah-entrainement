# Gorgias VR

Deux pages VR pour réviser le Gorgias de Platon, à ouvrir dans le navigateur du Meta Quest.

- `protocole/` : Protocole Gorgias, dix séquences de débat avec les concepts en objets.
- `souffle/` : Souffle VR, une phrase par souffle dans la spirale.

Cette branche ne contient que ces pages statiques. Le reste du dépôt n'est pas modifié.
